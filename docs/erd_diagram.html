Single Central Users Table

How authentication and roles work in InternshipMS

There is strictly one users table. All actors (Student, Company, and Admin) share this master authentication table. Their access privileges are governed by the role column ('admin', 'company', 'student').

1:1 Profile Separation

StudentProfile & CompanyProfile

Role-specific details are segregated cleanly: student academic records (GPA, resume, major) live in student_profiles, while employer organization details (website, verified status) live in company_profiles. Both link 1:1 via foreign key user_id with cascade on delete.
